# Site 1 — Sono e Cognição

Site institucional/acadêmico do projeto de extensão do curso de Fisioterapia da USCS.

## Como abrir
1. Extraia o ZIP.
2. Abra a pasta `site1-projeto-sono-cognicao` no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

## Conteúdo
- Introdução do projeto (texto fornecido).
- Descrição do local de realização (texto fornecido).
- Conteúdo educativo baseado no folder enviado.
- Foto da equipe.
- Quatro vídeos enviados.
- Considerações finais (texto fornecido) junto à foto.
- Seis referências bibliográficas do PDF do projeto.
- Folder educativo original em PDF.

## Arquivos
- `index.html`: estrutura e conteúdo.
- `style.css`: visual e responsividade.
- `script.js`: menu mobile.
- `assets/`: foto, vídeos e PDF educativo.

## Observação
O site usa fontes do Google Fonts quando há conexão com a internet. Os vídeos e documentos são locais e acompanham a pasta `assets`.
